Tutorial Teórico & Prático de Pseudo-código

Este guia foi desenvolvido para apoiar disciplinas de Estrutura de Dados. Aqui você encontrará os pseudo-códigos detalhados das quatro estruturas lineares fundamentais da ciência da computação.

Seção 1

1. Lista Sequencial (Vetor Estático/Dinâmico)

Estrutura que armazena elementos em posições de memória contíguas. O acesso direto é $O(1)$, mas a inserção/remoção pode exigir deslocamento $O(n)$.

1.1 Criação da Lista Sequencial 

ESTRUTURA ListaSequencial:
    Vetor dados[CAPACIDADE_MAX]
    Inteiro quantidade

FUNÇÃO criarLista():
    ListaSequencial L
    L.quantidade = 0
    RETORNAR L
FIM_FUNÇÃO

1.2 Buscar Elementos 

FUNÇÃO buscar(L, valor):
    PARA i DE 0 ATÉ (L.quantidade - 1) FAÇA:
        SE L.dados[i] == valor ENTÃO:
            RETORNAR i  // Retorna o índice onde foi encontrado
        FIM_SE
    FIM_PARA
    RETORNAR -1 // Não encontrado
FIM_FUNÇÃO

1.3 Inserir Elementos numa Posição 

FUNÇÃO inserir(L, valor, posicao):
    SE L.quantidade == CAPACIDADE_MAX ENTÃO:
        EXIBIR "Erro: Lista Cheia (Overflow)"
        RETORNAR FALSO
    FIM_SE

    SE posicao < 0 OU posicao > L.quantidade ENTÃO:
        EXIBIR "Erro: Posição Inválida"
        RETORNAR FALSO
    FIM_SE

    // Deslocar elementos para a direita para abrir espaço
    PARA i DE L.quantidade PASSO -1 ATÉ (posicao + 1) FAÇA:
        L.dados[i] = L.dados[i - 1]
    FIM_PARA

    L.dados[posicao] = valor
    L.quantidade = L.quantidade + 1
    RETORNAR VERDADEIRO
FIM_FUNÇÃO

1.4 Remover Elementos de uma Posição 

FUNÇÃO remover(L, posicao):
    SE L.quantidade == 0 ENTÃO:
        EXIBIR "Erro: Lista Vazia (Underflow)"
        RETORNAR FALSO
    FIM_SE

    SE posicao < 0 OU posicao >= L.quantidade ENTÃO:
        EXIBIR "Erro: Posição Inválida"
        RETORNAR FALSO
    FIM_SE

    // Deslocar elementos para a esquerda cobrindo a lacuna
    PARA i DE posicao ATÉ (L.quantidade - 2) FAÇA:
        L.dados[i] = L.dados[i + 1]
    FIM_PARA

    L.quantidade = L.quantidade - 1
    RETORNAR VERDADEIRO
FIM_FUNÇÃO
Seção 2

2. Lista Encadeada (Linked List)

Coleção de nós alocados dinamicamente. Cada nó armazena o dado e um ponteiro para o próximo nó.

2.1 Criação da Estrutura e Nó 

ESTRUTURA No:
    Dado valor
    Ponteiro proximo

ESTRUTURA ListaEncadeada:
    Ponteiro head // Cabeça da lista

FUNÇÃO criarListaEncadeada():
    ListaEncadeada L
    L.head = NULO
    RETORNAR L
FIM_FUNÇÃO

2.2 Buscar Elemento por Valor 

FUNÇÃO buscar(L, valorAlvo):
    Ponteiro atual = L.head
    Inteiro indice = 0

    ENQUANTO atual != NULO FAÇA:
        SE atual.valor == valorAlvo ENTÃO:
            RETORNAR indice // Retorna a posição do elemento
        FIM_SE
        atual = atual.proximo
        indice = indice + 1
    FIM_ENQUANTO

    RETORNAR -1 // Não encontrado
FIM_FUNÇÃO

2.3 Inserir Elemento no Início 

FUNÇÃO inserirNoInicio(L, novoValor):
    Ponteiro novoNo = ALOCAR_MEMORIA(No)
    novoNo.valor = novoValor
    
    // O novo nó aponta para onde a cabeça atual apontava
    novoNo.proximo = L.head
    
    // A cabeça da lista passa a ser o novo nó
    L.head = novoNo
    RETORNAR VERDADEIRO
FIM_FUNÇÃO

2.4 Remover Elemento por Valor 

FUNÇÃO removerValor(L, valorAlvo):
    SE L.head == NULO ENTÃO:
        EXIBIR "Lista Vazia"
        RETORNAR FALSO
    FIM_SE

    Ponteiro atual = L.head
    Ponteiro anterior = NULO

    // Caso o elemento a ser removido seja o primeiro
    SE atual.valor == valorAlvo ENTÃO:
        L.head = atual.proximo
        LIBERAR_MEMORIA(atual)
        RETORNAR VERDADEIRO
    FIM_SE

    // Busca pelo nó no restante da lista
    ENQUANTO atual != NULO E atual.valor != valorAlvo FAÇA:
        anterior = atual
        atual = atual.proximo
    FIM_ENQUANTO

    SE atual == NULO ENTÃO:
        EXIBIR "Valor não encontrado"
        RETORNAR FALSO
    FIM_SE

    // Bypass: Conecta o anterior ao próximo do atual
    anterior.proximo = atual.proximo
    LIBERAR_MEMORIA(atual)
    RETORNAR VERDADEIRO
FIM_FUNÇÃO
Seção 3

3. Pilha Sequencial (Array Stack - LIFO)

Estrutura que segue a regra LIFO (Last-In, First-Out). O último item a entrar é o primeiro a sair.

3.1 Criação da Pilha Sequencial 

ESTRUTURA PilhaSequencial:
    Vetor dados[CAPACIDADE_MAX]
    Inteiro topo

FUNÇÃO criarPilha():
    PilhaSequencial P
    P.topo = -1 // Indica que a pilha está vazia
    RETORNAR P
FIM_FUNÇÃO

3.2 Consultar o Topo (Peek) 

FUNÇÃO topo(P):
    SE P.topo == -1 ENTÃO:
        EXIBIR "Erro: Pilha Vazia"
        RETORNAR NULO
    FIM_SE
    RETORNAR P.dados[P.topo]
FIM_FUNÇÃO

3.3 Empilhar Elemento (Push) 

FUNÇÃO empilhar(P, valor):
    SE P.topo == (CAPACIDADE_MAX - 1) ENTÃO:
        EXIBIR "Erro: Estouro de Pilha (Stack Overflow)"
        RETORNAR FALSO
    FIM_SE

    P.topo = P.topo + 1
    P.dados[P.topo] = valor
    RETORNAR VERDADEIRO
FIM_FUNÇÃO

3.4 Desempilhar Elemento (Pop) 

FUNÇÃO desempilhar(P):
    SE P.topo == -1 ENTÃO:
        EXIBIR "Erro: Pilha Vazia (Stack Underflow)"
        RETORNAR NULO
    FIM_SE

    valorRemovido = P.dados[P.topo]
    P.topo = P.topo - 1
    RETORNAR valorRemovido
FIM_FUNÇÃO
Seção 4

4. Pilha Encadeada (Linked Stack)

Pilha dinâmica implementada com ponteiros. Permite crescimento flexível sem necessidade de capacidade limite pré-fixada.

4.1 Criação da Pilha Encadeada 

ESTRUTURA No:
    Dado valor
    Ponteiro proximo

ESTRUTURA PilhaEncadeada:
    Ponteiro topo

FUNÇÃO criarPilhaEncadeada():
    PilhaEncadeada P
    P.topo = NULO
    RETORNAR P
FIM_FUNÇÃO

4.2 Consultar o Topo (Peek) 

FUNÇÃO topo(P):
    SE P.topo == NULO ENTÃO:
        EXIBIR "Pilha Vazia"
        RETORNAR NULO
    FIM_SE
    RETORNAR P.topo.valor
FIM_FUNÇÃO

4.3 Empilhar (Push) 

FUNÇÃO empilhar(P, valor):
    Ponteiro novoNo = ALOCAR_MEMORIA(No)
    novoNo.valor = valor
    
    // O novo nó aponta para o topo anterior
    novoNo.proximo = P.topo
    
    // O topo é atualizado para o novo nó
    P.topo = novoNo
    RETORNAR VERDADEIRO
FIM_FUNÇÃO

4.4 Desempilhar (Pop) 

FUNÇÃO desempilhar(P):
    SE P.topo == NULO ENTÃO:
        EXIBIR "Erro: Pilha Vazia (Underflow)"
        RETORNAR NULO
    FIM_SE

    Ponteiro noRemovido = P.topo
    Dado valor = noRemovido.valor

    // Atualiza o topo para o próximo nó
    P.topo = P.topo.proximo

    LIBERAR_MEMORIA(noRemovido)
    RETORNAR valor
FIM_FUNÇÃO
