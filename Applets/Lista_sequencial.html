Aguardando Comandos
Seja bem-vindo à simulação de Lista Sequencial com limite máximo configurável! Caso tente inserir mais itens que o tamanho máximo informado, o sistema informará que o limite foi atingido.
1. Lista Vazia Redefine a quantidade de itens para 0, liberando todas as posições do vetor sequencial.
2. Inclusão de Item Insere o item. Se ultrapassar o tamanho máximo, avisa que o limite da lista foi atingido.
3. Exclusão de Item Remove o elemento desejado e reorganiza o vetor deslocando os itens à esquerda.
4. Indicar Posição Realiza uma busca sequencial $O(n)$ comparando elemento a elemento até informar o índice correto.
